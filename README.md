# Future Coach — LangGraph Multi-Agent Fitness System

> 🚧 Work in progress. Full README ships with U10.

A LangGraph hub agent routes fitness messages across three intents (coach, workout-generate, workout-log) to specialized sub-agents. Built as a take-home for Future Research's AI Engineer assessment.

## Quick start (placeholder)

```bash
uv sync
cp .env.example .env  # add your ANTHROPIC_API_KEY
uv run python -m fitness_agent
```

Open http://localhost:8000.
