Drop your fitness photos here (served at /static). Names used by the UI:

Dashboard cards:
  press.jpg      - Today's plan thumbnail (dumbbell press works well)
  deadlift.jpg   - "Coach a movement" card
  kettlebell.jpg - "Generate a workout" card
  torso.jpg      - "Log a set" card

My Workouts list thumbnails (one per workout category):
  arms.jpg       - workouts mentioning biceps/triceps/curls
  chest.jpg      - chest / bench press / push-ups
  back.jpg       - back / rows / pulldowns / pull-ups
  shoulders.jpg  - shoulders / deltoids / overhead press
  legs.jpg       - legs / squats / lunges / deadlifts / glutes
  core.jpg       - core / abs / plank
  fullbody.jpg   - full-body / total-body / circuit
  cardio.jpg     - cardio / running / SkiErg / jump rope / HIIT
  mobility.jpg   - mobility / stretch / yoga / warm-up
  workout.jpg    - generic fallback when no category matches

Missing files fall back to a generic stock photo. If the fallback also
fails, the `<img>` hides itself and the colored gradient behind it shows
through (no broken-image icon).
